# Payment Configuration

## Overview

Payment settings control invoicing, card processing, and recurring subscriptions. This guide covers the required fields for team administrators and finance stakeholders.

## Gateway Settings

The platform supports Stripe, Adyen, and a sandbox provider for testing. Use the sandbox environment during implementation and production values only after validation.

## Billing Rules

- Configure tax calculation before enabling billing.
- Set retries for failed invoice processing.
- Use a unique merchant identifier per region.
